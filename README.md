# Imparare FP in Scala

## Contenuto della repository

La repo contiene, suddivisi seguendo il libro "Functional Programming in Scala", tutti i codici che ho scritto per imparare il linguaggio. <br>
Il capitolo 01 della parte 1 è puramente teorico e spiega temi come i <a href="https://it.wikipedia.org/wiki/Effetto_collaterale_(informatica)">side effects</a> e la <a href="https://it.wikipedia.org/wiki/Trasparenza_referenziale">trasparenza referenziale</a>, dunque non c'è la directory *Part1-Introduction/Chapter01-WhatIsFP/*
